# Contributing

Contributions that improve evidence quality, source interpretation, accessibility, or test
coverage are welcome.

## Before opening a pull request

1. Keep observations neutral and reproducible.
2. Do not add personal contact details, email addresses, ABNs, or street addresses to derived
   datasets or fixtures.
3. Add a regression fixture and test for changes to normalisation or comparison behaviour.
4. Preserve primary-source attribution and evidence links.
5. Run the Python and site checks documented in the README.

When a source field is ambiguous, document the interpretation in an architecture decision
record before changing the data model.
